A design reference

Open a reference and retain context

Reach the intended verse or range without losing the search or conversation.

Design proposal · User validation required
Entry

Typed reference, search result or external deep link.

Proposed flow

  1. Resolve

    Recognise book, range and any edition; clarify ambiguity without guessing.

  2. Choose destination

    Use a focused preview or a chapter view with the requested verse in view.

  3. Orient

    Name the reference and edition; use a temporary cue only if helpful.

  4. Continue

    Read context, open a note or change translation using a semantic anchor.

  5. Return

    Restore the originating search or chat and its position.

Recovery and alternative routes

Unavailable edition, invalid reference or mapping gap: retain the requested target and offer an explicit alternative. Delayed layout must not recenter after manual scrolling.

What counts as a complete outcome

The passage is reached; no annotation is saved merely by opening it.

Research-informed design proposal

Engagement facets to specify

Possible situations: Lookup and verification, Encounter and curiosity. These are overlapping task contexts, not fixed user categories.

Specify the chosen purpose, passage unit, pace, participation, social setting, interpretive task, environment and disclosure or teaching responsibility. Use the scenario framework.
