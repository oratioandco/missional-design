PDF export fonts

MBD Canvas Sans Regular and Semibold are static weight instances derived from
Mona Sans by GitHub (2023), distributed under SIL OFL 1.1. The derived family
has been renamed to respect the reserved font name. Original copyright and
license records remain embedded. See MonaSans-OFL.txt.

Instrument Serif is converted from the existing WOFF2 to a TTF container for
PDF embedding. Copyright 2022 The Instrument Serif Project Authors, SIL OFL
1.1; see InstrumentSerif-OFL.txt.

Rebuild with scripts/prepare-canvas-pdf-fonts.py. PDF fonts are requested only
when the user chooses Download filled PDF; no answers are sent to a server.
